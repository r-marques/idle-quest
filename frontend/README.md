# My Next.js App

This is a simple Next.js application that includes a button to connect to MetaMask.

## Getting Started

To get started with this project, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   cd my-nextjs-app
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Open your browser**:
   Navigate to `http://localhost:3000` to view the application.

## Features

- Connect to MetaMask wallet using the ConnectButton component.
- Simple API endpoint that returns a greeting message.

## Usage

Click the "Connect" button to initiate the connection to your MetaMask wallet. Make sure you have the MetaMask extension installed in your browser.
